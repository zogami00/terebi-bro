Trusted networks widen who can reach the pairing prompt from outside the TV's own subnet. The pairing PIN and bearer tokens still gate every actual control action; an unpaired device that reaches the page can only see the pairing screen.

    MQTT

    Broker access equals control. Anyone who can publish to the <base>/command topic can drive this tablet — the controller token is not required for MQTT commands. The broker credentials are the only gate. Leave MQTT disabled unless you intend this.

    Media

    Media mode changes what the TV shows. Leave it off until you are in front of the TV and can see the result.
